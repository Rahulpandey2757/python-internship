# Pinnacle Labs - Python Development Tasks

Requires Python 3.9+. Tkinter ships with Python (on Linux: `sudo apt install python3-tk`).

| # | Task | Run | Install |
|---|------|-----|---------|
| 1 | Calendar & Reminder | `python 1_calendar_reminder/calendar_reminder.py` | - |
| 2 | Alarm Clock | `python 2_alarm_clock/alarm_clock.py` | - |
| 3 | Personal Blog Site | `cd 3_blog_site && python app.py` -> http://127.0.0.1:5000 (admin password: `admin123`, change in app.py) | `pip install flask` |
| 4 | Basic Calculator | `python 4_calculator/calculator.py` | - |
| 5 | Real-Time Chat | Terminal 1: `python 5_chat_app/server.py`; then `python 5_chat_app/client.py` in 2+ terminals | - |
| 6 | Online Quiz Platform | `cd 6_quiz_platform && python app.py` -> http://127.0.0.1:5000 | `pip install flask` |
| 7 | Weather Forecast | `python 7_weather_forecast/weather.py` (needs internet) | `pip install requests` |
| 8 | E-commerce Cart | `cd 8_ecommerce_cart && python app.py` -> http://127.0.0.1:5000. Test card: 4242 4242 4242 4242 | `pip install flask` |

Note: the Flask apps use port 5000, so run one at a time.
